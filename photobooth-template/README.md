# 大头贴边框模板（MARS CONCERT）

从一张已合成的大头贴成片里反推出来的空白边框模板，8 个照片位已清空。

| 文件 | 说明 |
| --- | --- |
| `template_transparent.png` | 透明底 PNG（1920×2860，RGBA），照片位 alpha = 0 |
| `template_green.png` | 绿幕版，照片位为纯绿 `#00FF00` |
| `template_transparent_2x.png` | 2 倍超分版透明底 PNG（3840×5720），照片位坐标全部 ×2 |
| `template_green_2x.png` | 2 倍超分版绿幕 |
| `slot_mask.png` | 8 个照片位的矩形蒙版（白 = 照片位） |
| `extract_template.py` | 生成 1 倍文件的脚本 |
| `assemble_2x.py` | 用超分后的边框合成 2 倍文件的脚本 |

## 照片位坐标（像素）

每个照片位 825×604。左列 x = 90，右列 x = 1005；四行 y = 135 / 774 / 1414 / 2053。

## 做法

成片左右两列放的是同一组照片，只是边框不同。所以同一张照片在左右两个位置逐像素对比：
相同的地方是照片，不同的地方一定是压在照片上的边框装饰（标题笔画、花、藤蔓、光晕）。

- 照片内容整块清空，不靠颜色猜，所以不会留下人像或红色背景。
- 压在照片上的装饰保留；它背后的照片像素由另一列提供，据此解出装饰的透明度和本色，
  边缘和光晕里不带照片的红色。
- 右侧红色边框的花和红色背景颜色接近，单靠对比会把花的一部分当成照片抠掉；
  这一侧的装饰按整块处理（闭合轮廓、填实内部），保证红花完整。
- 照片位以外的边框完全不透明，没有裁剪；只有紧贴照片位外沿的 3 像素被重建，
  用来去掉 JPEG 压缩渗进边框的红边。

## 已知限制

- 源图是 JPEG，装饰边缘的精度受压缩噪声限制。
- 左右两个边框的装饰重叠的位置（左上标题笔画附近、几个角上的花），照片底色是估算的，
  这些地方的装饰边缘不如别处干净。
- 左侧标题笔画的柔光是按单一颜色的半透明光晕还原的，颜色为估计值。
- 右侧红花为了保证完整，轮廓凹处可能带进一两个像素的照片红色（与花同色，肉眼基本不可见）。

## 2 倍版本

边框颜色用 Real-ESRGAN（x4plus）放大 4 倍后缩到 2 倍；透明度不经过 AI：照片位矩形在 2 倍尺寸下
重新精确绘制，装饰的透明度由 1 倍模板重采样。超分是推测出的细节，观感更清晰，但不是无损，
也不是矢量图——这类渲染图描成矢量只会损失细节。
